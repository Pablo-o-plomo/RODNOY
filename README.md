# РОДНОЙ

**РОДНОЙ** — Telegram-помощник для пожилых родителей, когда дети далеко. Он отвечает простыми словами, поддерживает, помогает с бытом, садом, ремонтом, техникой, документами, продуктами, фотографиями и проверкой подозрительных сообщений.

## Возможности MVP

- Стартовое меню с бытовыми сценариями.
- Ответы через OpenAI API простым и спокойным языком.
- Приём фотографий: бот сначала определяет тип фото и спрашивает, что нужно узнать.
- Фото-сценарии для продуктов, лекарств, растений, техники, холодильников, кондиционеров, документов и квитанций.
- Голосовые сообщения: скачивание voice, распознавание через OpenAI transcription и обработка как обычного текста.
- Антимошенник: предупреждения о кодах из SMS, данных карты, срочных переводах и подозрительных ссылках.
- Уведомление ребёнка через `CHILD_TELEGRAM_ID`.
- Напоминания: разовые и ежедневные.
- SQLite-хранилище для пользователей, сообщений, напоминаний и контекста фото.

## Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Нужен Python 3.11 или новее.

## Настройка `.env`

Скопируйте пример:

```bash
cp .env.example .env
```

Заполните значения:

```env
TELEGRAM_BOT_TOKEN=токен_бота_от_BotFather
OPENAI_API_KEY=ваш_openai_api_key
DATABASE_URL=sqlite:///rodnoy.sqlite3
CHILD_TELEGRAM_ID=telegram_id_ребёнка
ADMIN_TELEGRAM_ID=telegram_id_админа
```

`CHILD_TELEGRAM_ID` — это Telegram ID ребёнка, которому бот отправляет уведомления. Для MVP достаточно указать один ID.

## Локальный запуск

```bash
python -m rodnoy_bot.bot
```

После запуска откройте бота в Telegram и отправьте `/start`.

## Запуск через Docker

```bash
docker build -t rodnoy-bot .
docker run --env-file .env -v $(pwd)/data:/app/data rodnoy-bot
```

Если хотите хранить базу в папке `data`, укажите в `.env`:

```env
DATABASE_URL=sqlite:///data/rodnoy.sqlite3
```

## Команды бота

- `/start` — начать работу и показать меню.
- `/help` — показать помощь.
- `/menu` — показать главное меню.
- `/add_reminder` — добавить напоминание.
- `/my_reminders` — показать активные напоминания.
- `/cancel` — отменить текущее действие.

## Как добавить ребёнка для уведомлений

1. Узнайте Telegram ID ребёнка, например через специального ID-бота в Telegram.
2. Добавьте ID в `.env`:

```env
CHILD_TELEGRAM_ID=123456789
```

3. Перезапустите бота.

Бот уведомляет ребёнка, если пользователь нажал **📞 Связаться с детьми**, написал тревожную фразу вроде «мне плохо», прислал подозрительное сообщение или попросил сообщить детям из напоминания.

## Важные правила безопасности

- Бот не ставит медицинские диагнозы и не назначает лечение.
- При рисках советует обратиться к врачу, детям или в экстренную службу.
- При опасных работах с электричеством, газом, хладагентом, пайкой и давлением предупреждает отключить питание и вызвать специалиста при отсутствии опыта.
- Бот не просит банковские данные и предупреждает не сообщать коды, пароли и данные карты.
