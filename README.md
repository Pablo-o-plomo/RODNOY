# РОДНОЙ

**РОДНОЙ** — Telegram-помощник для пожилых родителей, когда дети далеко. Он отвечает простыми словами, поддерживает, помогает с бытом, садом, ремонтом, техникой, документами, продуктами, фотографиями и проверкой подозрительных сообщений.

## Возможности MVP

- Стартовое меню с бытовыми сценариями.
- Ответы через OpenAI API простым и спокойным языком.
- Приём фотографий: бот сначала определяет тип фото и спрашивает, что нужно узнать.
- Фото-сценарии для продуктов, лекарств, растений, техники, холодильников, кондиционеров, документов и квитанций.
- Голосовые сообщения: скачивание voice, распознавание через OpenAI transcription и обработка как обычного текста.
- Голосовой режим ответов: бот может отправлять текст, а затем короткое voice/audio-сообщение через OpenAI TTS.
- Антимошенник: предупреждения о кодах из SMS, данных карты, срочных переводах и подозрительных ссылках.
- Кнопка связи с родственником с мягкой заглушкой для MVP.
- Напоминания: разовые и ежедневные.
- SQLite-хранилище для пользователей, сообщений, напоминаний и контекста фото.

## Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Нужен Python 3.11 или новее.

## Настройка `.env`

Скопируйте пример:

```bash
cp .env.example .env
```

Заполните значения:

```env
TELEGRAM_BOT_TOKEN=токен_бота_от_BotFather
OPENAI_API_KEY=ваш_openai_api_key
DATABASE_URL=sqlite:///rodnoy.sqlite3
ENABLE_TTS=true
OPENAI_TTS_MODEL=gpt-4o-mini-tts
OPENAI_TTS_VOICE=alloy
CHILD_TELEGRAM_ID=0
ADMIN_TELEGRAM_ID=0
```

`CHILD_TELEGRAM_ID` и `ADMIN_TELEGRAM_ID` необязательны. В простом MVP семейные уведомления отключены: оставьте значения пустыми или равными `0`, и бот будет работать как обычный Telegram-помощник.

## Локальный запуск

```bash
python -m rodnoy_bot.bot
```

После запуска откройте бота в Telegram и отправьте `/start`.

## Запуск через Docker

```bash
docker build -t rodnoy-bot .
docker run --env-file .env -v $(pwd)/data:/app/data rodnoy-bot
```

Если хотите хранить базу в папке `data`, укажите в `.env`:

```env
DATABASE_URL=sqlite:///data/rodnoy.sqlite3
```

## Команды бота

- `/start` — начать работу и показать меню.
- `/help` — показать помощь.
- `/menu` — показать главное меню.
- `/add_reminder` — добавить напоминание.
- `/my_reminders` — показать активные напоминания.
- `/voice` — включить или выключить голосовые ответы.
- `/cancel` — отменить текущее действие.


## Голосовой режим ответов

Голосовой режим — дополнительная функция. Основной бот продолжает работать текстом, даже если TTS недоступен.

Чтобы включить генерацию голосовых ответов на сервере, добавьте в `.env`:

```env
ENABLE_TTS=true
OPENAI_TTS_MODEL=gpt-4o-mini-tts
OPENAI_TTS_VOICE=alloy
```

Пользователь включает или выключает голосовые ответы для себя командой `/voice` или кнопкой **🔊 Голосовой режим** в меню. Настройка хранится отдельно для каждого Telegram-пользователя.

Когда режим включён, бот сначала отправляет полный текстовый ответ, а затем короткую голосовую версию. Если ответ длиннее 500 символов, в TTS уходит сокращённая версия, а полный ответ остаётся в тексте.

Для Telegram voice лучше подходит OGG/OPUS. Если на сервере установлен `ffmpeg`, бот автоматически конвертирует mp3 в ogg и отправит voice-сообщение. Если `ffmpeg` недоступен, бот отправит mp3 как audio-файл. Если OpenAI TTS или конвертация не сработали, бот не падает и оставляет только текстовый ответ.

## Связь с родственником

В текущем простом MVP семейные связи и уведомления детям отключены. Если пользователь нажимает **📞 Связаться с детьми** или кнопку **📞 Сообщить детям** в напоминании, бот отвечает: «Пока связь с родственником не настроена.»

Переменные `CHILD_TELEGRAM_ID` и `ADMIN_TELEGRAM_ID` оставлены в `.env.example` для будущего этапа. Они необязательны; пустые значения или `0` не мешают запуску бота.

## Важные правила безопасности

- Бот не ставит медицинские диагнозы и не назначает лечение.
- При рисках советует обратиться к врачу, детям или в экстренную службу.
- При опасных работах с электричеством, газом, хладагентом, пайкой и давлением предупреждает отключить питание и вызвать специалиста при отсутствии опыта.
- Бот не просит банковские данные и предупреждает не сообщать коды, пароли и данные карты.
